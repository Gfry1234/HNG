Smart Utility 📱
A lightweight, efficient mobile application built with React Native designed to streamline everyday productivity. Smart Utility combines essential mathematical tools with a streamlined task management system.

📥 Download
Note: Since this is a debug build, your phone may warn you about "Unknown Sources." You can safely bypass this to install.
Features
1. Unit Converter
Easily switch between different measurement systems without needing a calculator.

Length: Meters, kilometers, miles, and feet.

Weight: Kilograms, grams, pounds, and ounces.

Temperature: Celsius, Fahrenheit, and Kelvin.

2. Task Scheduler
A minimalist To-Do system designed to keep you focused.

Add Tasks: Quickly jot down daily objectives.

Mark as Completed: Interactive checkboxes to track progress.

Persistent Storage: Your tasks remain saved even after closing the app.

🛠️ Tech Stack
Framework: React Native

Package Manager: pnpm

Environment: Android Studio (Gradle)

⚙️ Installation & Setup (For Developers)
Prerequisites
Node.js (Latest LTS)

pnpm (npm install -g pnpm)

Android Studio configured with SDK and Emulator.

1. Clone & Install
Bash
git clone https://github.com/Gfry1234/HNG.git
cd HNG
pnpm install
2. Configure pnpm for React Native
Ensure you have a .npmrc file in the root with:

Plaintext
node-linker=hoisted
3. Launch
Start the Metro Bundler: pnpm start

Run on Android: pnpm android
